## 规范与剩余覆盖范围

金额采用 Decimal 和 JSON 字符串；正式事实仍是 Beancount 文件。路由、读取、查询、原位编辑和事务写入分模块；业务输入不接受任意文件路径。
全部 Python 操作通过 uv。ROADMAP 按用户要求原地勾选，未移走任务；每项独立本地提交，未推送。
恢复遵守「先核对、后补齐」，外部变化冲突不覆盖，错误不静默忽略。前后端测试与 CI 不读取私人账本或凭据。

未覆盖代码主要是防御性错误分支：文件链接拒绝、Git 命令不可用、恰好读取期间变化、原始交易头/分录无法定位、BOM 首行替换、原子替换清理，以及浏览器存储异常、旧响应丢弃等。核心写入与错误账本门禁有明确测试。
前端函数覆盖率 88.33%，低于语句覆盖率；未覆盖函数主要是少量 UI 回调，不掩饰为全覆盖。
